# 🥐 Dulce Trigo — Sistema de Gestión de Panadería

Dulce Trigo es un sistema web de gestión para una panadería, desarrollado como proyecto de práctica y portfolio personal.

Su objetivo es facilitar la administración de productos, ventas, stock y clientes mediante una interfaz sencilla, organizada y adaptable a distintos dispositivos.

## ✨ Funcionalidades

* **Dashboard:** resumen de ventas, productos y stock, gráfico de ventas, actividad reciente y alertas de stock bajo.
* **Productos:** alta, edición, búsqueda, filtros y eliminación lógica de productos.
* **Ventas:** registro de ventas, selección de clientes y actualización automática del stock.
* **Stock:** consulta del inventario y control de existencias.
* **Reportes:** estadísticas, historial de ventas y exportación a Excel.
* **Clientes:** registro, edición, búsqueda y administración de clientes activos e inactivos.

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Chart.js
* SweetAlert2
* ExcelJS
* LocalStorage

## 📱 Diseño responsive

La interfaz está adaptada para computadoras, tablets y celulares.

## 💾 Almacenamiento

Los datos se guardan en el navegador mediante LocalStorage. El proyecto no utiliza una base de datos ni un backend.

## 🚀 Cómo ejecutar el proyecto

1. Clonar o descargar este repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar `index.html` en el navegador.

También se puede utilizar la extensión Live Server de Visual Studio Code.
